# AL-BARAKA COSMETIQUE — FOCUS

Responsive Arabic-first product landing page for FOCUS, with a customer delivery form and WhatsApp order handoff.

## Preview

Open index.html in a browser. Customers can enter their delivery details and review them in a WhatsApp draft before sending.

## Before publishing

- Confirm the WhatsApp number is correct.
- Confirm delivery details, ingredients, usage directions, and product claims.
- The static site does not store customer form entries.
