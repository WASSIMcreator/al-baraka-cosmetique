# AL BARAKA — FOCUS + Cosmétique + Clothes

Page de vente "warm edition" (العربية par défaut / Français) pensée pour les pubs :
- Hero sombre et chaud, boîte FOCUS détourée en 3D avec les 6 ingrédients qui tournent autour
- Offres 1 / 2 / 3 boîtes (199 / 349 / 479 DH), paiement à la livraison, livraison gratuite
- Formulaire court (nom, téléphone, ville) → commande envoyée sur WhatsApp
- Mode pub : les visiteurs venant d'une pub (utm / fbclid / ttclid) ne voient que FOCUS
- Packs soin + vêtements (3D) pour les autres visiteurs

## Fichiers
`index.html`, `styles.css`, `script.js`, `focus-bottle.png` (boîte détourée), `focus-hero.jpg`, `focus-trio.jpg`, `focus-lifestyle.jpg`

## À régler dans `script.js` (en haut)
- `metaPixel` / `tiktokPixel` : vos IDs de pixel
- `OFFERS` : prix des offres
- `adMode` : `false` pour montrer toute la boutique même aux visiteurs des pubs
- `PACKS` / `CLOTHES` : prix d'exemple à remplacer
